# Winter Fox

Versão enxuta do presente de aniversário.

## Fluxo

**Menu → Esteira → Vinho → Bruxaria → Pins → Final**

O projeto possui quatro minigames:

1. **Esteira do café**
   - os itens passam pela tela;
   - clique apenas nos alimentos do pedido;
   - são três pedidos.

2. **Vinho bem gelado**
   - segure o botão para resfriar;
   - solte quando o marcador entrar na faixa perfeita;
   - são três rodadas progressivamente mais difíceis;
   - a faixa diminui e a velocidade oscila para evitar decorar apenas o tempo.

3. **Ritual da bruxa**
   - observe a sequência de ingredientes;
   - repita na mesma ordem;
   - três rodadas.

4. **Pins**
   - jogo da memória;
   - encontre quatro pares.

Depois dos quatro jogos, aparece a tela final de aniversário.
