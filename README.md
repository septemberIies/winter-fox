# Winter Fox

Versão enxuta do presente de aniversário.

## Fluxo

**Menu → Esteira → Bruxaria → Pins → Final**

O projeto agora possui somente três minigames:

1. **Esteira do café**
   - os itens passam pela tela;
   - clique apenas nos alimentos do pedido;
   - são três pedidos.

2. **Ritual da bruxa**
   - observe a sequência de ingredientes;
   - repita na mesma ordem;
   - três rodadas.

3. **Pins**
   - jogo da memória;
   - encontre quatro pares.

Depois dos três jogos, aparece a tela final de aniversário.
